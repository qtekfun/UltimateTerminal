# UltimateTerminal — Task plan

Rules: one task at a time, on its `feat/<task>` branch, with `./gradlew check` green before closing it. Mark `[x]` when done. Every task must be verifiable (a test or a described manual check).

## Phase 0 — Foundations and risk prototypes
- [x] **T00 Base project**: Android module, Gradle KTS, `libs.versions.toml`, Hilt, Compose, Material 3 theme, `strings.xml` en/es, SPDX headers, `LICENSE` (GPLv3), `targetSdk` 28.
  - *Verification:* `./gradlew assembleDebug` builds and the app starts with an empty screen.
- [x] **T01 CI and quality**: detekt, ktlint, Lint (warnings as errors), Kover with thresholds, dependency verification, license/Play Services check, GitHub Actions workflow, Dependabot.
  - *Verification:* a test PR passes CI; a Play Services dependency added on purpose makes it fail.
- [x] **T02 proot prototype (biggest risk)** *(builds and is packaged for the 3 ABIs; running on a device was still to be validated, see `DECISIONS.md`)*: build proot and talloc from source with the NDK in the build, packaged as `.so`; start an Alpine rootfs and run a command.
  - *Verification:* on a real device (API 26–28 and a recent version), `proot` runs `/bin/sh` and `uname -a`; document `seccomp`, `link2symlink` and limits in `SPEC.md` (section 9).
- [x] **T03 PTY + terminal view prototype** *(the emulator and view build and are tested on the host with 145 upstream tests plus our own; the real PTY, drawing, keyboard and gestures were not validated on a device, see `DECISIONS.md`)*: integrate Termux's `terminal-emulator` and draw it in Compose (Canvas); validate `vim`, `tmux` and `htop`.
  - *Verification:* manual demo; performance, selection and IME decision documented.
- [~] **T04 Adaptive resizing prototype** *(implemented, tested on the host and **verified on a device**: on the Pixel 8 with the keyboard, and on the Huawei MRO-W09 tablet (Android 12) in landscape, portrait, with and without keyboard and in a resized floating window, `stty size` matches what is visible every time (fourth round). Still missing: the system split screen (`--windowingMode 3/4` fails on that EMUI) and rotation to 180°/270°; see `DECISIONS.md`, T04)*: full-screen terminal on a tablet with multi-window, rotation and keyboard; the PTY receives the right size.
  - *Verification:* on a tablet, `stty size` matches what is visible after every change; no bands or gaps.

- [~] **T24 Fedora as a distro** (user request: their usual distro; it was in the SPEC §2 backlog): add Fedora to the catalog (`data/rootfs`) with its official container image.
