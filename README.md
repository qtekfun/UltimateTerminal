# UltimateTerminal

Modern Linux terminal for Android, adaptive on tablets, with full distributions (Debian, Ubuntu,
Alpine) running through proot. Terminal only: no graphical environment. Free software
(GPL-3.0-or-later), no Google services, no tracking. Work in progress: see `SPEC.md` and `PLAN.md`.
